## 📊 Обзор

PerfTune AI - это продвинутый инструмент для мониторинга и оптимизации производительности системы с современным графическим интерфейсом. Предоставляет мониторинг системных ресурсов в реальном времени, анализ процессов и возможности оптимизации.

## ✨ Возможности

### 🔍 Мониторинг в реальном времени
- **Использование CPU/памяти процесса** - Отслеживание конкретных процессов или системы в целом
- **Мониторинг дискового I/O** - Активность диска в реальном времени в МБ/с
- **Использование сети** - Мониторинг сетевой пропускной способности
- **Системные ресурсы** - Общая загрузка CPU и памяти
- **Сглаженные датчики** - Анимированные индикаторы с EMA-сглаживанием

### 🛠️ Инструменты оптимизации
- **Оптимизация системы** - Настройка параметров ядра
- **Быстрый анализ** - 15-секундный анализ производительности процесса
- **Сравнение с базовым уровнем** - Сравнение текущей производительности с сохраненной базой
- **Откат изменений** - Восстановление предыдущих настроек системы

### 📈 Визуализация
- **Современный GUI** - Интерфейс на PyQt6 с анимациями
- **Темная тема** - Профессиональный темный интерфейс
- **Адаптивный дизайн** - Поддержка различных разрешений экрана
- **Эффекты и тени** - Глубокие тени и размытия для лучшего UX

## 📋 Требования

### Системные требования
- **ОС**: Linux (рекомендуется Ubuntu 20.04+ или CentOS 8+)
- **Права доступа**: Root для функций оптимизации
- **Память**: 512 МБ RAM минимум
- **Диск**: 100 МБ свободного места
